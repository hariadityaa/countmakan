        Setup (API keys)
        
        Keys stay on this phone only.
        
        
        
        
        
          How to get a free Gemini key
          
        About 2 minutes. You don't need a credit card.
        
          
          
            
        1. Open aistudio.google.com/apikey on this phone or a computer.
          2. 
            
        2. Sign in with any Google account.
          3. 
            
        3. If asked, accept the terms.
          4. 
            
        4. Tap Create API key. If it asks for a project, pick the default one.
          5. 
            
        5. Copy the key.
          6. 
            
        6. Come back here and paste it into "Gemini API key". Then tap Save keys and Test keys.
          7. 
          
        
          
        Good to know:
        
          
          
            
        • The free key has a daily limit. When it's reached, the app switches to a lighter model.
          • 
            
        • On the free tier, Google may use your photos and descriptions to improve its products. Adding billing to the key stops this.
          • 
            
        • Keep the key private. Anyone with it can use your quota.
          • 
          
        
        
        
        
        
          Optional: DeepSeek key (paid)
          
        Only needed if you have a paid DeepSeek account. The app works with just a Gemini key.
        
          
          
        
        
        
        
          
          
        
        
        
          
        
          The setup link saves these keys on another phone. Treat it like a password.
          
        
        
          Provider order
          
        
          Tried top to bottom. If one fails, the next one is used.
